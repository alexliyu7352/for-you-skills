# Attribution and evidence provenance

The corpus is an English synthesis of the repository owner's complete X recommendation-algorithm research report, archived in the [original report](provenance/research-report.zh-CN.md). Stable claim IDs, source-unit mappings and original URLs preserve the ability to inspect the underlying evidence.

Primary code references include [xai-org/x-algorithm](https://github.com/xai-org/x-algorithm) and [twitter/the-algorithm](https://github.com/twitter/the-algorithm), alongside the official product documentation and other sources listed in the [source registry](knowledge/sources.json). Each third-party source retains its original license and ownership. The [MIT license](LICENSE) covers original instructions, synthesis and helper code; it does not relicense quoted or linked third-party material.

The [Agent Skills specification](https://agentskills.io/specification) defines the portable directory format. The separate [Skills CLI](https://github.com/vercel-labs/skills) provides the documented installation mechanism. Neither project is bundled as a runtime dependency.

This project is independent of X Corp., xAI and the agent vendors named in the compatibility documentation. It does not claim access to private production configuration or guarantee exposure results.

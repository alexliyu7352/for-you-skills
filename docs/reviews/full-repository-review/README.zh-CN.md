## 会影响用户的主要问题

| 问题 | 实际影响 | 记录 |
| --- | --- | --- |
| 把“公开资料没有证实某种 hashtag 扣分公式”写成“没有这种公式” | 把不知道说成确定不存在，辟谣回答可能产生新的错误保证 | KD-01 |
| 部分源码条件在整理时丢失或添加错误 | 例如长度特征并非所有请求都发送；MediaInjected 也不要求此前检测结果必须存在 | C-01、C-02 |

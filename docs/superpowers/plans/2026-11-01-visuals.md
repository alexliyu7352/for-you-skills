# Visual workflow implementation plan

> **For agentic workers:** Use superpowers:executing-plans. The user has approved execution and publication; continue without another approval round.

**Goal:** Add usable image creation with portable private style memory to For You Skills.

**Architecture:** One specialist owns creation, tool discovery and preference decisions. A standard-library helper stores versioned profiles outside installation directories. The router and checklist bundle that workflow and helper so independent installs still work.

**Tech Stack:** Markdown, JSON, Python 3.9+, unittest, existing deterministic builder.

**Spec:** `docs/superpowers/specs/2026-11-01-visuals.md`

## Global constraints

- English runtime instructions; replies follow the user.
- Python 3.9+ and standard library only.
- Existing 578 knowledge entries and source mapping unchanged.
- No live X mutation or provider credential storage.
- Actual tool discovery; mock availability is identified as such.

## Review focus

- A temporary style must not change persistent defaults.
- A newly installed standalone skill must locate the same private preferences.
- Importing a malformed or conflicting profile must preserve existing data.
- A missing generation tool must not produce a false image-delivery claim.
- A conceptual illustration must not fabricate code, screenshots or numeric evidence.

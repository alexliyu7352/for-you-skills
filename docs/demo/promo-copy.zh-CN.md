# For You Skills：中文发布文案

每天第二篇帖子，曝光就打六折？

看到这种运营建议，我想先知道：代码到底写了什么。

我把 X.com / Twitter 推荐算法的公开源码分析，做成了 For You Skills，一套可以直接提问的开源技能。

一天能发几条？长文该发 Post 还是 Article？配图、外链、互动权重该怎么理解？

把问题交给它，它会查内置知识库，解释对应代码，给出建议、适用条件和原始链接。证据不足的地方，也会说清楚。

准备发稿时，还能检查开头、长度、配图和论证，给出具体改稿。

视频里是两次实际使用的结果：核查“第二篇六折”的说法，以及把我的 Article 曝光经历改成一篇导读。保留了源码和完整问答；没有把个人曝光数字当作技能效果。

支持 Claude Code、Codex、Cursor 等。安装后直接用自己的话问，不用记八个技能名。

项目：https://github.com/alexliyu7352/for-you-skills

拿一个你真正纠结过的 X.com 问题试试。

## 配套回复：安装与研究入口

先装总路由即可：

```bash
npx skills add alexliyu7352/for-you-skills --skill x-assistant
```

本次演示采用固定公开代码版本 `5ed7963`，知识库研究截止于 2026-10-29；不代表全部线上配置。

## 图片替代文字

封面：For You Skills，基于 X.com / Twitter 公开推荐代码分析的开源技能。展示运营问答、源码核对和发布前审稿三个用途。

问答对照图：用户问每天第二篇是否少四成曝光。回答说明，启用作者多样性并采用演示版本公开默认参数时，0.625 是同一批排序里同一作者第二名候选的倍率，不是每天第二篇的曝光比例；新内容已准备好时，不必只因这一说法等待四小时。固定版本代码不能保证下一条曝光。
